# Return Policy

Northstar Supply accepts returns within 30 calendar days of delivery. The delivery date on your order starts the return window. Items must be unused, in their original packaging, and include all accessories. Personalized products and final-sale items cannot be returned unless they arrive damaged or defective.

To start a return, contact support with your order number and reason for returning. Support will open a ticket and arrange a return authorization. Do not send an item back before receiving authorization. Creating a ticket does not itself authorize a return or issue a refund.

Customers pay return shipping for change-of-mind returns. Northstar Supply covers return shipping when an item is damaged, defective, or incorrect. Report damage within 7 days of delivery and keep the packaging. The team may request photographs.

Orders that are still processing may be cancelled by contacting support. Shipped orders cannot be cancelled in transit. Customers can request a return after delivery. If an item falls outside the 30-day return window, support can review a warranty issue, but cannot guarantee a return exception.
